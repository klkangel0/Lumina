# Lumina

Aplicación web de gestión interna para Assotea.

## Estructura

- `lumina-api/`: API Node/Express + Prisma (MySQL/MariaDB)
- `lumina-app-react/`: Frontend React
- `docs/`: documentación

## Desarrollo local

- Backend: `cd lumina-api && npm run dev` (puerto 4001)
- Frontend: `cd lumina-app-react && npm start` (puerto 3000)
